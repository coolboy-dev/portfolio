A C++ web server

About 1,300 lines of C++ with no dependencies. With one event loop per CPU core it handles around 665,000 requests a second, roughly level with nginx on the same laptop, in under 12 MB of memory.

The jump from one loop to many didn't touch the rest of the code: the workers, the cache and the rate limiter stayed the same.

GST bill checker

A cashback app's users were waiting days for their shopping bills to be approved. This checks a bill read by OCR in microseconds and says approve, review or reject, with the reason.

It catches fake or misread GSTINs and edited totals, and it notices when the same bill comes in twice. There's no AI in it, only arithmetic, and the demo here runs the real logic in your browser.

    Transaction categorizer

    Bank statements in India are full of lines like PAYTM-9876543210@ptybl-2501, and the same shop shows up in a dozen spellings. This pipeline sorted 50,000+ of them into categories with a plain English summary.

    A vector search places most lines by meaning. Only the ones it can't place go to an LLM, which kept it cheap enough to run without a GPU.

    Go, Python, vector search, Claude and OpenAI APIs

    No GPU anywhere. The model is only called when matching by meaning fails.
