Data, evaluation, fraud and risk

UPI City: a test bench that tells you if a fraud model actually works

In production you only see the fraud you caught, never what slipped past, so nobody can say how good a detector is. UPI City simulates a payment network where I inject the fraud myself, so every payment has a known answer and any detector can be scored honestly.

It graded eight detectors. Four scored below chance, and none of the off the shelf ones beat simply sorting payments by amount. The video shows mine and the best open source one (PyOD HBOS) scoring the same payments live.

Backend and performance

A C++ web server that keeps up with nginx

About 1,300 lines of C++17, nothing beyond the standard library and the Linux kernel. One epoll loop per core, a worker pool, an LRU file cache and a per IP rate limiter.

Going from one event loop to one per core took it from about 158k to 665k requests a second without touching the workers, the cache or the limiter. Pick a load level on the right to compare it with nginx on the same machine.

Documents and OCR

A GST bill checker that clears clean bills instantly

Built after reading one cashback app's reviews, where real users' bills sat "under review" for days. It reads an Indian GST bill after OCR and returns approve, review or reject, with reasons.

It verifies the GSTIN check digit and repairs one character OCR misread (1 and I, 0 and O), checks that CGST equals SGST and the totals reconcile, and flags the same bill uploaded twice. No model, just arithmetic. Try it: the demo is the real logic running in your browser.

    AI agents and RAG

    Messy bank lines in, clean categories out

    UPI transaction lines are unreadable on purpose, and one shop shows up in a dozen spellings, so text matching fails. This pipeline matches on meaning instead: a vector database finds the closest known merchant, and only the strings it can't place go to an LLM.

    It runs with no GPU, which keeps the cost small. The same order works on product names, invoice lines or CRM fields: cheap matching first, AI for the leftovers.
